# My Personal Portfolio

Personal portfolio of Francesco Chiaramonte (Software QA).

## Sections
* About (`/`)
* Career (`/career`)
* Projects (`/projects`)

## Tech Stack
* TypeScript, Next.js (App Router), React, Tailwind CSS
* Framer Motion for page transitions
* Playwright for E2E tests

## Development
```bash
npm install
npm run dev      # http://localhost:3000
npx playwright test
```

Most of the content (hobbies, socials, skills, projects, languages) lives in `src/lib/data.ts`.
